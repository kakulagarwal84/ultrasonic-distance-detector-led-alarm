# Ultrasonic Distance Detector with LED Alarm

## Objective

Develop an Arduino-based obstacle detection system using an ultrasonic sensor and LED alarm.

## Components Used

* Arduino Uno
* Ultrasonic Distance Sensor
* LED
* Connecting Wires

## Working Principle

The ultrasonic sensor sends sound waves and measures the time taken for the echo to return. The Arduino calculates the distance to the object. When an object is detected within 20 cm, the LED turns ON. Otherwise, the LED remains OFF.

## Features

* Real-time distance measurement
* Obstacle detection
* Automatic LED indication
* Simulated using Tinkercad
